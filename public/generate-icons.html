🎨 Генератор иконок PWA

Нажмите кнопки ниже, чтобы скачать иконки для вашего приложения

192x192

512x512

📋 Инструкция:

  1. Нажмите "Скачать icon-192.png" и сохраните файл
  2. Нажмите "Скачать icon-512.png" и сохраните файл
  3. Переместите оба файла в папку public/ вашего проекта
  4. Запушьте изменения в GitHub: git add . && git commit -m "Add PWA icons" && git push
  5. Netlify автоматически задеплоит новую версию ✅
